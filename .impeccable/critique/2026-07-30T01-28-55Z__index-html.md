## Priority Issues

1. [P1] Raw UA focus ring on the name: pressing 1 or clicking home stamps the default stepped outline around the h1 — the one focus state not styled, on the most prominent element. Fix: .name:focus { outline: none; } (focus management itself is correct).
2. [P1] Dead tabs ambiguous + costly: strikethrough reads deleted; title="coming soon" never reaches touch/keyboard; ~2.1:1 text. 40% of a 5-item nav. (User has chosen to keep them for now; softer fix: visible "soon" affix or higher-contrast treatment.)
3. [P2] Intro replays for early leavers: switching tabs within ~2.25s cancels animations before .intro-done is stamped. Fix: also stamp on animationcancel or a one-shot ~2.3s timer.
4. [P2] Title/history inconsistency: direct #projects load or back/forward leaves the bare title; clicks set "projects · ...". Fix: set title unconditionally in activate().
5. [P3] 9px kbd badges below legibility floor; 10-11px costs nothing.
